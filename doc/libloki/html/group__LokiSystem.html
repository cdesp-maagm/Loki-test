Affecter un facteur d'échelle de déplacement.

Pour une longueur d'onde λ0, le facteur d'échelle sera typiquement de la forme λ0 / 4π. Les déplacements seront calculés dans la même unité que λ0.

Paramètres
selfLa configuration à modifier.
