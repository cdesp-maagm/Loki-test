Enregistrer un paquet de données au format miniSEED.

Cette fonction attend un tableau d'échantillons dont les éléments ont un type de la forme :

struct Sample {
uint32_t channel;
float value;
... // Autres données spécifiques
}

On doit avoir sample_size == sizeof(struct Sample)

Paramètres
selfLe formateur de séries temporelles miniSEED.
filenameLe nom du fichier de destination.
timestampLa date du paquet de données (inutilisée pour ce format).
file_changeFaut-il ouvrir un nouveau fichier de destination ou poursuivre le fichier précédent ?
dataLes données à écrire.
lengthLe nombre d'échantillons à écrire.
max_channelsLe nombre maximal de voies que ce formateur peut traiter.
channelsUn masque indiquant les voies à traiter.
sample_sizeLa taille d'un échantillon, en octets.
sampling_frequencyLa fréquence d'échantillonage (inutilisée pour ce format).
