Description détaillée

Ce module fournit une API en espace utilisateur pour accéder aux composants modulateur et démodulateur du FPGA.

Il s'appuie sur un module noyau Linux à travers les interfaces IOCTL et MMAP. Ce module noyau implémente les mécanismes de plus bas niveau pour l'accès au matériel (registres, DMA).
