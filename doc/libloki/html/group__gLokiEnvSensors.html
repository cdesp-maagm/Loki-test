Description détaillée

Ce module fournit une API en espace utilisateur pour accéder aux composants de gestion des capteurs d'environnement interfacés avec le FPGA.

Il s'appuie sur un module noyau Linux à travers les interfaces IOCTL et MMAP. Ce module noyau implémente les mécanismes de plus bas niveau pour l'accès au matériel (registres, DMA).

◆ LokiEnvSensors_work()

void * LokiEnvSensors_work ( void * ptr)
static

Traiter un tableau d'échantillons issu d'un transfert DMA.

Cette fonction est exécutée dans un thread démarré par LokiEnvSensors_start_streaming. Elle se termine lorsqu'une demande d'arrêt est émise par LokiEnvSensors_stop_streaming.

Si la constante USE_MMAP est définie, elle s'appuie sur la fonction mmap pour se synchroniser avec le pilote du circuit modem et accéder au tampon de données de chaque transfert en mode zero-copy. Si la constante USE_MMAP n'est pas définie, la fonction fread est utilisée.

Cette fonction remplit la FIFO de sortie avec des paquets d'échantillons convertis par la fonction LokiEnvSensors_set_packet_item.

Paramètres
ptrLe module d'acquisition courant.
Renvoie
Rien.
