LokiDisplacement * LokiDisplacement_new ( LokiEllipseEstimator * estimator,
LokiFIRFilter * filter,
unsigned throttle,
float scale,
float tau[static 3],
float sampling_frequency )

Construire un calculateur de déplacement.

Le facteur d'échelle détermine l'unité de distance utilisée en sortie de LokiDisplacement_work. On choisira typiquement scale = λ0 / 2πN où λ0 est la longueur d'onde du laser, dans l'unité de mesure de distance souhaitée, et N est le nombre de réflexions.

Paramètres
estimatorUn filtre adaptatif d'estimation d'ellipse.
filterUn filtre passe-bas pour éliminer le déplacement fictif.
throttleLa périodicité de mise à jour des paramètres de l'ellipse.
scaleUn facteur d'échelle pour la valeur des déplacements calculés.
tauLes constantes de temps du filtrage des paramètres de l'ellipse, en secondes (0 : axes; 1 : centre; 2 : angle).
sampling_frequencyLa fréquence d'échantillonnage, en Hz
Renvoie
Une instance de LokiDisplacement.

bool LokiDisplacement_work ( LokiDisplacement * self,
float x,
float y,
float * x_norm,
float * y_norm,
float * out )

Calculer le déplacement courant.

Pour un déplacement d et une longueur d'onde λ0, en mètres, cette fonction retourne : scale * 4π / λ0 * d

Paramètres
selfUne instance de LokiDisplacement.
xLa coordonnée X du point courant de l'ellipse.
yLa coordonnée Y du point courant de l'ellipse.
x_normLa coordonnée X du point courant de l'ellipse, ramené sur le cercle unité.
y_normLa coordonnée Y du point courant de l'ellipse, ramené sur le cercle unité.
outLe déplacement calculé.
Renvoie
true à chaque période de décimation.
