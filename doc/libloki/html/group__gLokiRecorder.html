◆ LokiRecorder_work()

void * LokiRecorder_work ( void * ptr)
static

Enregistrer les données.

Cette fonction est exécutée dans un thread démarré par la fonction LokiRecorder_start. Elle reçoit les données de la FIFO d'entrée de l'enregistreur courant et les passe à un formateur qui les enregistre. L'enregistrement se poursuit jusqu'à ce qu'une demande d'arrêt soit effectuée par la fonction LokiRecorder_stop, ou jusqu'à ce que la durée totale d'enregistrement soit atteinte.

Paramètres
ptrL'enregistreur courant.
Renvoie
Rien.
