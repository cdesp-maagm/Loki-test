◆ LokiSocketServer_start()

int LokiSocketServer_start ( LokiSocketServer * self,
LokiFIFO * in,
size_t cid )

Démarrer un serveur.

Cette fonction est non bloquante. Elle démarre deux threads: un pour traiter les paquets de données d'entrée, l'autre pour gérer les connexions des clients et leur transmettre les données aux clients.

Paramètres
selfLe serveur à démarrer.
inLa FIFO contenant les données à transmettre.
cidLe numéro de consommateur de ce serveur dans sa FIFO d'entrée.
Renvoie
Le code d'erreur retournée par pthread_create.
