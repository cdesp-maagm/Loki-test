LokiFIFO * disp_out,
size_t cid )

Démarrer l'acquisition et le traitement.

Cette fonction est non bloquante. Elle crée un nouveau thread pour le traitement des données en provenance du modem et démarre celui-ci.

Paramètres
selfLe système à démarrer.
channelsUn masque indiquant les voies à traiter, -1 pour toutes les voies.
modem_outLa FIFO qui recevra les données de sortie du démodulateur.
disp_outLa FIFO qui recevra les valeurs de déplacement.
cidLe numéro de consommateur de ce système pour la FIFO modem_out.
Renvoie
Le code d'erreur retourné par LokiModem_start_streaming

◆ LokiSystem_work()

void * LokiSystem_work ( void * ptr)
static

Calculer le déplacement à partir des données démodulées.

Cette fonction est exécutée dans un thread démarré par LokiSystem_start_streaming. Elle consomme les données de la FIFO d'entrée et alimente la FIFO de sortie, jusqu'à la demande d'arrêt par LokiConsumer_stop.

Paramètres
ptrLe système courant.
Renvoie
Rien.
