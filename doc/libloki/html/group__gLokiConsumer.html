Description détaillée

Ce module fournit une implémentation de référence d'un consommateur qui lit les données dans une FIFO et qui ne les utilise pas.

Il peut être utilisé comme bouchon en sortie d'une FIFO dont les données ne sont pas utilisées.

Il peut aussi servir d'exemple de référence pour construire d'autres consommateurs
