Description détaillée

Représentation d'une FIFO.

Le contenu de la FIFO est construit comme une liste cirulaire dont les maillons sont de type LokiFIFORecord. Cette liste circulaire n'est pas représentée explicitement dans la structure LokiFIFO. Elle est allouée à la suite du tableau consumer_records.
