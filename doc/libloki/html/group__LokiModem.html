Description détaillée

Ce module fournit une API en espace utilisateur pour accéder aux composants modulateur et démodulateur du FPGA.

Il s'appuie sur un module noyay Linux à travers les interfaces IOCTL et MMAP. Ce module noyau implémente les mécanismes de plus bas niveau pour l'accès au matériel (registres, DMA).

Démarrer l'acquisition et le traitement des échantillons démodulés.

Cette fonction démarre les transferts par DMA depuis le démodulateur. À chaque fois qu'un transfert DMA est terminé, elle copie les données dans la FIFO de sortie.

Paramètres
selfLes données du modem.
channelLe numéro de la voie, -1 pour acquérir toutes les voies.
simulateFaut-il simuler un capteur logiciellement ?
rawFaut-il conserver les valeurs d'échantillons en virgule fixe ?
outLa FIFO où enregistrer les échantillons.
Renvoie
Un code d'erreur.
