◆ LokiFIFO_get_consumer_item()

void * LokiFIFO_get_consumer_item ( LokiFIFO * self,
size_t cid )

Obtenir une référence vers l'élément courant en lecture.

Cette fonction retourne un pointeur sur un élément disponible en lecture dans la FIFO. Le consommateur peut traiter cet élément et appeler LokiFIFO_pull lorsque le traitement est terminé.

Cette fonction bloque le producteur tant que la FIFO est vide.

Paramètres
selfLa FIFO à interroger.
cidL'identifiant du consommateur courant.

◆ LokiFIFO_pull()

void LokiFIFO_pull ( LokiFIFO * self,
size_t cid )

Libérer l'élément courant en lecture.

Avant d'appeler cette fonction, le producteur doit obtenir une référence vers l'élément à lire en appelant LokiFIFO_get_consumer_item. Cette fonction décrémente le niveau courant de la FIFO.

Cette fonction bloque le consommateur jusqu'à ce que l'élément courant ait été consommé par tous les consommateurs.

Paramètres
selfLa FIFO à modifier.
cidL'identifiant du consommateur courant.
