\doxysubsubsection{Description détaillée}
Ce module fournit une implémentation de référence d\textquotesingle{}un consommateur qui lit les données dans une \doxylink{group__gLokiFIFO}{FIFO} et qui ne les utilise pas. 

Il peut être utilisé comme {\itshape bouchon} en sortie d\textquotesingle{}une FIFO dont les données ne sont pas utilisées.

Il peut aussi servir d\textquotesingle{}exemple de référence pour construire d\textquotesingle{}autres consommateurs
