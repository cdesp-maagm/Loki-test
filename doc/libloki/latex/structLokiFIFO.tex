\doxysubsection{Description détaillée}
Représentation d\textquotesingle{}une FIFO. 

Le contenu de la FIFO est construit comme une liste cirulaire dont les maillons sont de type \doxylink{structLokiFIFORecord}{Loki\+FIFORecord}. Cette liste circulaire n\textquotesingle{}est pas représentée explicitement dans la structure \doxylink{structLokiFIFO}{Loki\+FIFO}. Elle est allouée à la suite du tableau {\ttfamily \doxylink{structLokiFIFO_a0b8567cedd77bd8962713393a7a1d2ab}{consumer\+\_\+records}}.
