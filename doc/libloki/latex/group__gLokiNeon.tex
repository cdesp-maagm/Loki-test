\doxysubsubsection{Description détaillée}
Sur les architectures ARM qui supportent les instructions SIMD NEON, ce fichier inclut directement l\textquotesingle{}en-\/tête {\ttfamily arm\+\_\+neon.\+h} officiel. 

Pour les autres architectures, ce fichier fournit des implémentations en C standard de quelques fonctions intrinsics pour les types flottants 32 bits. Cela permet, par exemple, de tester sur PC une fonction destinée à un processeur ARM.
