
Ce dossier contient le code source VHDL et les projets Vivado pour
la configuration du FPGA.

Contenu de ce dossier
=====================

| Dossier    | Description                                                                 |
|:-----------|:----------------------------------------------------------------------------|
| `lib`      | La bibliothèques de composants utilisables dans les projets.                |
| `projects` | Les projets Vivado avec les entités principales et les scripts de synthèse. |

Dans le dossier `lib`, le test des modules s'effectue avec le simulateur GHDL.
